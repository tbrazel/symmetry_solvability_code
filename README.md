# Supplementary code for *Symmetry and solvability*

This repository contains supplementary code for the paper *Symmetry and solvability: Galois groups of equivariant enumerative problems*, by [Thomas Brazelton](), [Alberto Landi]() and [Sidhanth Raman](). The code is a [GAP](https://www.gap-system.org/) package that machine-checks the paper's group-theoretic claims.

**AI Disclosure**: AI was used to set up the architecture of this repo and the `crossref.py` script which builds dynamic theorem numbers into the GAP comments from theorem labels in the `.aux` file of the paper.

## Where things are

The package itself lives in [`symmetric-galois/`](symmetric-galois/) — see [`symmetric-galois/README.md`](symmetric-galois/README.md) for the quick start, the layout of the package, and how to add a group or a claim.
